# Pet Groom — лендінг грумінг-салону

Статичний сайт: HTML + CSS + JavaScript, без фреймворків.

## Як влаштовано

```
src/                    ← тут редагуємо
  css/
    main.css            список усіх файлів стилів у потрібному порядку
    base/               кольори, шрифти, кнопки, сітка, анімації
    components/         шапка, меню, вікно «Записатися», форма, акції
    sections/           блоки сторінки: hero, послуги, роботи, майстри…
    phones/             правила для телефонів
    desktop/            правила для комп'ютера
  js/
    common.js           спільне для всіх сторінок: посилання, вікно запису, меню
    home/               скрипти головної, по файлу на блок (номер = порядок)
assets/                 ← це завантажує браузер (не редагувати вручну)
  css/styles.min.css    зібрано з src/css
  js/common.min.js      зібрано з src/js/common.js
  js/home.min.js        зібрано з src/js/home/*
  images/, video/
index.html, blog/       сторінки
```

## Робота з кодом

Один раз встановити залежності:

```
npm install
```

Під час роботи — автоматично перезбирати при кожній зміні в `src/`:

```
npm run dev
```

Зібрати один раз (обов'язково перед комітом / публікацією):

```
npm run build
```

Зібрані файли в `assets/` комітяться разом із `src/`, тому хостингу не потрібно нічого збирати.

## Важливо

- **Порядок файлів має значення.** Стилі, що йдуть пізніше в `src/css/main.css`, перекривають попередні.
  Скрипти головної склеюються в порядку номерів у назвах (`src/js/home/01-…`, `02-…`) і списку в `build.mjs`.
- Скрипти — звичайні (не модулі) і мають спільні глобальні назви: `src/js/home/*` користуються `LINKS`,
  `openBooking`, `showToast` тощо з `src/js/common.js`.
- Контакти (Telegram, WhatsApp, Viber, телефон, TikTok, Threads) — на початку `src/js/common.js`, об'єкт `LINKS`.
- Відео першого екрана обрізані до 5 с, бо кожен кліп показується 4,5 с (`SCENE_MS` у `src/js/home/01-hero-video.js`).
